# Results Viewer

[![Python](https://img.shields.io/badge/Python-3.10%2B-3776AB?logo=python&logoColor=white)](https://www.python.org/)
[![uv](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/astral-sh/uv/main/assets/badge/v0.json)](https://github.com/astral-sh/uv)
[![Streamlit](https://img.shields.io/badge/Streamlit-1.x-FF4B4B?logo=streamlit&logoColor=white)](https://streamlit.io)

Interactive Streamlit UI for reviewing rAIdiologist NPC screening predictions alongside transformer self-attention heatmaps and dense-net activation maps.

---

## Features

- **Attention overlay** - overlay transformer attention maps on the MRI slice grid with adjustable opacity, threshold, and colormap
- **Head selection** - inspect individual attention heads or take the max / average across all heads
- **Segmentation contour** - optionally overlay the segmentation mask as a contour
- **TP / TN / FP / FN filtering** - filter the case list to a confusion-matrix category with live statistics
- **Attention histogram** - plotly histogram of attention values with adjustable threshold markers
- **Batch export** - save overlaid images for every filtered case plus a `filtered_results.csv`
- **Saving configuration** - save the configuration as a .json file and automatically load them
---

## Quick start

### Using `uv`

```bash
# 1. Navigate to the ui/ directory
cd discrimination_module/ui

# 2. Create the virtual environment and install all dependencies
uv sync

# 3. Launch the viewer you need
uv run viewer-trans      # Transformer / ViT attention maps
```

That's it. `uv sync` creates an isolated `.venv` automatically — no manual activation required.

## Configuration

On first launch the **Configurations** panel expands automatically. Fill in the directory paths and click **Apply Configurations**. Click **Save State** to persist your settings across sessions.

| Field | Description                                                                                                                                      |
|---|--------------------------------------------------------------------------------------------------------------------------------------------------|
| **Image Directory** | Folder containing NIfTI images (`*image*.nii.gz`)                                                                                                |
| **Attention Map Directory** | Folder with heatmaps (`*pb_pred*.nii.gz` / `*heatmap*.nii.gz`). These are by default the suffix generated by the pipeline in the root directory. |
| **Segmentation Directory** | *(Optional)* Folder with segmentation masks                                                                                                      |
| **Prediction CSV Directory** | Path to the results `.csv` or `.xlsx` file                                                                                                       |
| **ID Globber Regex** | Regex used to extract case IDs from filenames (default `\w{0,5}\d+`)                                                                             |
| **Output Directory** | Where saved overlay images are written                                                                                                           |

Saved states are stored in `.config/` next to the viewer script and are timestamped so you can switch between sessions.

## Prediction CSV format

The CSV must have the case ID as the **index** (leftmost column) and the following columns:

| Column | Required | Description |
|---|---|---|
| `Decision_0` | Yes | Binary prediction (0 / 1) |
| `Prob_0` | Yes | Raw probability after sigmoid |
| `Truth_0` | No | Ground-truth label — enables TP/TN/FP/FN filtering |

> If the CSV comes from `simple_inference` it will have `OverallPrediction` instead of `Prob_0`. The viewer detects this and converts automatically.



---

## Attention map format

Files must match the pattern `{ID}_pb_pred.nii.gz` (or contain `heatmap` / `pb_map`). The ID must be extractable by the configured **ID Globber Regex**. Attention maps may live in the same directory as the images or a separate folder.
